## 2026-10-22 — Создан скилл «Прожарка идеи»

**Задача:** не из ROADMAP — инструмент для работы над идеями до появления задачи.

**Что сделано:**

- Создан скилл `.opencode/skills/idea-grill/` — разговор, который превращает сырую идею в оформленную задачу.
- Три режима: прожарка одной идеи, отбор из списка идей, проверка готовой идеи на дыры.
- 7 раундов разговора (адаптивно, от 3 до 7): разогрев → проблема → данные → место → жёсткая прожарка → оценка → оформление.
- Оценка по четырём осям (польза, усилия, риск, уверенность), формула итога, правила ранжирования и сравнения вариантов.
- Три исхода: делать, отложить, отклонить. Задача получается не всегда.
- Правила оформления: история в ROADMAP (номера существующих историй не меняются) + папка задачи по шаблону из `AGENTS.md`.
- В `AGENTS.md` добавлен раздел 9 с описанием скилла.

**Файлы:**

- `.opencode/skills/idea-grill/SKILL.md`
- `.opencode/skills/idea-grill/references/questions.md` — банк вопросов по раундам
- `.opencode/skills/idea-grill/references/scoring.md` — оси, шкала, формула, ранжирование
- `.opencode/skills/idea-grill/references/task-template.md` — как оформить историю и папку задачи
- `.opencode/skills/idea-grill/assets/idea-sheet.md` — растущая карточка идеи
- `AGENTS.md` — раздел 9 «Скилл „Прожарка идеи“»

**Проверка:**

- Скилл загружен инструментом `skill` по id `idea-grill` — отображается в списке доступных, текст и список файлов на месте.
- Все ссылки из `SKILL.md` ведут на существующие файлы внутри папки скилла.
