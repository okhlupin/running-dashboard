⚙ Настроить KPI-группы

Перетащите карточку в другую группу, чтобы поменять её место. Клик по «×» скрывает карточку — она переместится в блок «Скрытые карточки», клик по «↩» возвращает её обратно. В макете изменения применяются сразу; в боевой версии «Сохранить макет» фиксирует раскладку в localStorage, а «Отмена» откатывает её.
