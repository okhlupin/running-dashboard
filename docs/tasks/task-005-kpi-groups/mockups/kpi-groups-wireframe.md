## 4. Поведение и правила

| Действие | Результат |
|---|---|
| Клик по иконке/названию группы | Сворачивает/разворачивает группу, меняется `aria-expanded` и шеврон |
| Клик по карточке | Открывает панель детализации (поведение прежнее) — клик по шапке группы не должен его вызывать |
| Клик по «⚙ Настроить KPI» | Открывает модальное окно настройки раскладки |
| Drag & drop карточки | Карточка переезжает между группами, раскладка применяется сразу |
| Перезагрузка страницы | Восстанавливаются раскладка, свёрнутость, скрытые группы и карточки |
| «Сбросить к умолчанию» | Возвращает раскладку из `payload.json` → `defaultKpiGroups` |
| Ключ отсутствует / JSON битый | Используется `defaultKpiGroups`, приложение работает без ошибок |

## 5. Правила сетки

| Уровень | Свойство | Значение |
|---|---|---|
| Сетка секций | `grid-template-columns` | `repeat(auto-fit, minmax(420px, 1fr))`, `gap: 16px` |
| Сетка карточек в группе | `grid-template-columns` | `repeat(auto-fit, minmax(190px, 1fr))`, `gap: 14px` |
| Заголовок группы | flex | `display:flex; align-items:center; justify-content:space-between` |
| Свёрнутое состояние | `display:none` | на `.kpi-group-body`, с переходом по высоте |
| Уважение к настройкам ОС | `@media (prefers-reduced-motion: reduce)` | отключить переходы |
