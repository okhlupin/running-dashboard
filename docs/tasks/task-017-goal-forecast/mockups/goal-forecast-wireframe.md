## 3. Формулы (зафиксированы)

```
remainingKm        = max(0, goalKm - actualKm)
daysLeft           = дней от today до target включительно
requiredKmPerWeek  = remainingKm / (daysLeft / 7)
paceDeltaKmPerWeek = paceKmPerWeek - requiredKmPerWeek
daysNeeded         = ceil(remainingKm / paceKmPerWeek * 7)
forecastDateISO    = addDaysISO(today, daysNeeded - 1)   ← сегодня = 1-й день
daysEarly          = max(0, daysLeft - daysNeeded)
daysLate           = max(0, daysNeeded - daysLeft)

status = 'achieved' | 'no-data' | 'on-track' | 'behind'
```

> Важно: `- 1` в `addDaysISO`. Без него «на N дней позже» считается на день больше.
> Пример: цель 75 км, факт 42.5 км, темп 20 км/нед, сегодня 22 окт, срок 31 окт
> → daysNeeded = 12 → прогноз 2 ноя → daysLeft = 10 → «на 2 дня позже».

## 5. Изменение строки в шапке с бегуном

```
Было:
┌──────────────────────────────────────────────────────────────────────────┐
│  Цель месяца (2026-10): 88.0 / 75 км (117%)                             │
│                                          🏃‍♂️                      🏁   │
└──────────────────────────────────────────────────────────────────────────┘

Стало:
┌──────────────────────────────────────────────────────────────────────────┐
│  Цель месяца (2026-10): 88.0 / 75 км (117%) · Прогноз: цель уже достигнута│
│                                          🏃‍♂️                      🏁   │
└──────────────────────────────────────────────────────────────────────────┘
```

Варианты суффикса:

| Статус | Суффикс |
|---|---|
| achieved | `· Прогноз: цель уже достигнута` |
| on-track | `· Прогноз: 26 окт, на 5 дней раньше` |
| behind | `· Прогноз: 12 фев, на 43 дня позже` |
| no-data | `· Прогноз: нет данных о темпе` |

При узком экране суффикс скрывается (`@media`), полная версия — в карточке.

## 6. Правила отображения

| Элемент | Правило |
|---|---|
| Дата прогноза | `fmtDateShort` в карточке, `fmtDateFull` в шапке |
| Числа | `fmtNum` (кириллическая локаль `ru-RU`) |
| Бейдж статуса | зелёный `badge-green` (on-track/achieved), красный `badge-red` (behind), жёлтый `badge-yellow` (no-data) |
| Дефицит темпа | красным `var(--danger)`, если `paceDeltaKmPerWeek < 0` |
| Прогресс-бар | `.progress-mini`, ширина = `min(100, actualKm / goalKm * 100)` |
| Окно темпа | подпись «Темп за 28 дней», число берётся из `state.settings.forecastWindowDays` |
| Русские окончания | через общий хелпер: 1 день / 2 дня / 5 дней / 43 дня / 1 месяц |
| Тёмная и светлая тема | только существующие CSS-переменные |
