# Дашборд бегуна PRO

Личная страница для учёта тренировок и разбора бега: объём, темп, пульс, регулярность, «план против факта» и прогноз, успею ли я к цели. Всё приложение лежит в одном HTML-файле — открыли в браузере и работаете. Ничего не надо устанавливать, запускать сервер или заводить аккаунт.

---

## Быстрый старт

1. Скачайте файл **`running-dashboard 3.html`** из этого репозитория.
2. Откройте его двойным щелчком в любом современном браузере (Chrome, Edge, Firefox, Safari).
3. Нажмите **«⚡ Демо-данные (60)»**, чтобы посмотреть, как всё работает, на наборе из 60 тренировок. Потом очистите демо и вносите свои.

> Приложение работает и без интернета. Данные хранятся только в вашем браузере — на сервер GitHub ничего не отправляется.

## Что внутри

### Карточки показателей (KPI)

Десять главных цифр, собранных в четыре смысловые группы:

| Группа | Показатели |
|---|---|
| 📦 Объём | за 7 дней, за месяц, число пробежек, самая длинная пробежка |
| ⚡ Темп | средний темп, средняя скорость |
| ❤️ Пульс | средний пульс, максимальный пульс |
| 🔥 Регулярность | серия дней подряд, динамика к прошлому периоду |

Группы можно свернуть, развернуть, перетащить карточки между группами и спрятать ненужные. Настройка сохраняется.

### Графики

- **Динамика объёма** — по месяцам и по неделям, с планом и фактом.
- **Темп и пульс** — со скользящим средним; ось можно переключить «по датам» или «по дистанции».
- **Распределение по пульсовым зонам** — по числу бегов или по километрам. Сами зоны ЧСС настраиваются.
- **Тепловая карта за год** — цветом показан километраж за каждый день. Клик по дню открывает детали.

### План, цели и прогноз

- Недельный план тренировок и месячная цель по объёму.
- Посуточное сравнение «план против факта».
- **Прогноз даты достижения цели** по вашему текущему темпу — сразу видно, успеваете ли вы к объёму месяца, квартала или года.

### Журнал тренировок

- Таблица всех пробежек с фильтрами по периоду, типу тренировки, метрике и возрасту данных.
- Клик по строке или по графику открывает карточку тренировки с деталями и формулами расчёта.
- Ручной ввод, **импорт CSV** (с проверкой и предпросмотром) и **экспорт/импорт JSON**.

### Ввод голосом и разбор текста (ИИ)

- Кнопка **«🎙 Ввод голосом (ИИ)»**: записываете прогулку обычной фразой — приложение разбирает текст и заполняет форму.
- Кнопка **«✨ Разобрать»** в форме тренировки: вводите текст вручную — поля заполняются сами.
- Разбор работает через API DeepSeek. Ключ вводится в настройках и хранится только в вашем браузере. Без ключа приложение полностью работоспособно — просто этих двух кнопок не будет.

### Оформление

Светлая и тёмная темы, переключаются одной кнопкой **«🌓 Тема»**.

## Где хранятся данные

Все данные лежат в памяти браузера (в том, что разработчики называют `localStorage`) — это такая память страницы, которая остаётся после закрытия вкладки и пропадает при очистке истории браузера.

Ключи хранения:

| Что | Ключ |
|---|---|
| Тренировки | `run_pro_runs_v2` |
| Недельные планы | `run_pro_plans_v2` |
| Цели | `run_pro_goals_v2` |
| Настройки | `run_pro_settings_v2` |

**Обязательно делайте резервную копию.** Кнопка **«⬇ JSON»** выгружает все данные в файл, кнопка **«⬆ JSON»** загружает их обратно. Данные из другого браузера или с другого компьютера тоже переносятся так.

## Как ведётся работа над проектом

Задачи не выдумываются на ходу — берутся из `docs/ROADMAP.md`. Каждая история из дорожной карты проходит путь:

```
история в ROADMAP.md
   → папка docs/tasks/task-NNN-<имя>/ (описание, промпт, примеры, макеты)
   → правка running-dashboard 3.html
   → проверка в браузере
   → запись в docs/CHANGELOG.md и статус «выполнено» в TASK.md
```

Подробные правила — в [AGENTS.md](AGENTS.md).

Готовые задачи:

|---|---|
| [task-005-kpi-groups](docs/tasks/task-005-kpi-groups/TASK.md) | Группировка карточек KPI по смысловым блокам |
| [task-017-goal-forecast](docs/tasks/task-017-goal-forecast/TASK.md) | Прогноз даты достижения цели по текущему темпу |

## Скилл «Прожарка идеи»

В проекте лежит скилл [`.opencode/skills/idea-grill/`](.opencode/skills/idea-grill/SKILL.md) — разговор, который превращает сырую идею в оформленную задачу проекта: задаёт вопросы, оценивает идею по четырём осям (польза, усилия, риск, уверенность), сравнивает варианты и в конце выдаёт готовую историю для `ROADMAP.md` и папку задачи.

Три режима: прожарка одной идеи, отбор из списка идей, проверка готовой идеи на дыры.

## Требования

- Любой современный браузер (Chrome, Edge, Firefox, Safari).
- Интернет не нужен. Для голосового ввода и разбора текста нужен ключ API DeepSeek.
- Всё, что нужно для разработки, — это текстовый редактор. Сборка, установка зависимостей и сервер не требуются.
